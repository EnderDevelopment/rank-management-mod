# Rank Management Mod

A Fabric mod for managing player ranks in Minecraft.

## Features

- Create custom ranks with unique IDs and names.
- Assign ranks to players using in-game commands.

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or higher

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/rank-management-mod/releases).
2. Place the mod file in your `mods` folder.
3. Launch Minecraft with Fabric.

## Usage

### Commands

| Command | Description |
|---------|-------------|
| `/ranks create <id> <name>` | Create a new rank with the specified ID and name. |
| `/ranks give <player> <id>` | Assign the rank with the specified ID to the player. |
| `/ranks remove <player> <id>` | Remove the rank with the specified ID from the player. |

### Permissions

- Players with the necessary permissions can create, assign, and remove ranks.

## Configuration

The mod does not require any additional configuration files. All settings are managed through in-game commands.
